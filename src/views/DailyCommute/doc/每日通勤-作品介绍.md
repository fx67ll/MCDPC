# 每日通勤 · Daily Commute

> 一个只服务于"我每天上下班那两段路"的私人地图助手
>
> 在线访问：https://map.fx67ll.com/commute ｜ 技术栈：Vue 2 + 高德地图 JSAPI 2.0

---

## 一、一句话作品简介

每天跨江通勤 25 公里，我烦透了出门前要打开地图 App、手动输两段路、再心算时间。于是给自己做了一个网页：**出门前在手机上看一眼，今天堵不堵、走哪条路、几点该出门，一眼就清楚。** 下了地库上车，直接用车机导航。它不是导航工具，是出门前三秒的决策入口。它不为任何 KPI 服务，只为我和她每天那两段在路上的时间服务。

---

## 二、痛点：不是一段路，是三段锚点串起来的两段

我住在南京江北（江浦），我公司在城南花神科技广场，女朋友公司在江宁（比星咖啡那一片），单程要跨江约 25 公里。真实路线是固定的**三段锚点、两段串联**：

> 家（江浦）→ 我公司（花神）→ 她公司（江宁）

每天真实的纠结是：

- **两个人交接班**：第一段我开（家→花神公司），到公司换她开第二段（花神→江宁她公司）；两段用时都要算准，因为交接时间是卡死的
- 走**五桥（免费）**还是**三桥（收费）**？哪条不堵？
- 我现在出门，**几点能到公司？她几点能到她那？会不会迟到？**
- 下班从她公司（江宁）出发，经过我公司再回家，**几点能到家？**
- 下雨/早晚高峰/周一早会，**路况会不会突然变**？

而通用地图 App 是给所有人用的：它只会算**两个点**之间的路线。像我这种"我开第一段、她开第二段"的固定串联，每段都要手动输一次、再自己心算两段加起来多久。**第二段去她那边的路，通用地图根本不会帮你记。**

> 这不是一个效率工具，是一个"消除不确定感"的工具。知道几点出门就不慌，知道几点到她公司、几点到我那就都有谱——这就是它的人文价值。

## 三、它长什么样、能做什么

### 3.1 打开即所见，零输入

- 根据当前时段自动判断方向：**0:00–12:00 上班，12:00–24:00 下班**；
- 根据手机定位离起点/终点的远近，自动选中"上班"或"下班"页签；
- 定位失败也不空等，直接按时段兜底判断，绝不卡 loading。

### 3.2 三段锚点 · 两段串联用时自动相加

- **固定路线**：家（江浦）→ 我公司（花神科技广场）→ 她公司（江宁·比星咖啡）
- **路线一 · 绿水湾路（五桥免费）**：日常 90% 走这条，免费，但早上过桥必堵
- **路线二 · 虎桥路（三桥收费）**：应急兜底路线，收费，但早上过桥不堵，用来确保不迟到
- 两条路线同时实时计算，一眼判断今天该不该换应急路线
- 下班自动对称反向（江宁·比星 → 花神 → 江浦）
- **每段用时拆开显示，两段实时相加**：不用自己心算"家到我公司多久 + 我公司到她公司多久"
- 非选中路线只算耗时、不重画地图，避免闪烁

### 3.3 拥堵一眼看懂

- 横向彩色路况条：按路段标"畅通/缓行/拥堵/严重拥堵"；
- 地图右侧垂直路况细条（Web 端）+ 移动端详情抽屉里的路况概览卡片；
- **"我"的实时标记**：把定位点投影到规划路线上，按累计路程算出 0–100% 进度，实时显示"我走到哪了"。

### 3.4 抵达时间与迟到提醒

- 预计到达公司 / 到家时间大卡片，点击即可复制；
- 上班迟到时卡片自动切红色警示；下班到家卡片用深蓝底黄字，一眼可辨；
- 关键时间点时间线（TimeLine）、分段用时（每一段多久）。

### 3.5 顺手的小事

- 当前天气卡片（带缓存，不重复请求），点击复制天气文字；
- 一键跳高德网页版导航，Web / 移动端行为统一；
- 骨架屏、卡片淡入上浮动效、悬浮微动效——细节是给每天用的人看的。

### 3.6 隐私设计（私人工具的底线）

- 起点对外只显示"**江浦**"这个区域名，不暴露具体小区/楼号；
- 独立的"隐藏路段"配置：家到上车点那段不画在地图上，也不计入分段行；
- 数据全部本地配置，不社交、不上传、不做用户体系。

## 四、技术实现：小工具里的工程化打磨

| 模块 | 做法 | 解决的问题 |
| --- | --- | --- |
| 高德并发限流 | 自建串行请求队列，相邻请求间隔 400ms，8 秒超时兜底 | 高德 1 秒内 Driving.search 不能超过 3 次，否则卡死 |
| 快速刷新防抖 | 连续点刷新只处理最后一次，排队中的旧请求直接丢弃 | 旧结果污染当前界面、队列堆积卡顿 |
| 路线切换合并 | 快速切路线一时合并为一次重绘 | 减少高德请求、避免地图反复闪烁 |
| 定位投影算进度 | 遍历 rawRoute.steps[].path 累计距离，找最近路径点按占比返回百分比 | 在拥堵条上实时标出"我"在哪 |
| 坐标转换 | 百度 BD-09 → 高德 GCJ-02 自动转换 | 用百度拾取器取点，不用手工换算 |
| 配置化 | POINTS / ROUTES / TABS 全是对象数组，路线支持任意数量途经点 | 以后改路线、加途经点只改数据，不动逻辑 |
| 自适应 | Web 面板 + 移动端底部悬浮胶囊条两套布局 | 开车时手机、工位上电脑都能用 |

> 主页面 `DailyCommute/index.vue` 约 10 万字符，拆成 12 个子组件（ArriveCard / CongestionBar / WeatherCard / SegmentDuration / TimeLine…），从 0.3.0 到 0.3.5 密集迭代了 6 个版本。

## 五、为什么是现在：AI 时代的个人作品

这个作品本身没有大模型、没有 AI 功能——它是规则 + 地图 API 的成熟小工具。但它的**诞生方式**贴着 AI 时代：

- **这是我想了很久、但一直没动手的事**：路线规划、高德对接、拥堵条、定位投影、移动端适配、动效……没有 AI 的时候，一个人攒好几个周末也推不动，想想就放下了；
- **有了 AI 之后**：Claude Code 一路辅助，业余时间，从 0.3.0 到 0.3.5，6 个版本把限流、防抖、动效、自适应全磨到位；
- **AI 不是这个作品的功能，是让一个普通人把"想了很久的小事"做出来的那把火。**

> 大家都在用 AI 做"加速产出"，我用 AI 兑现了一个搁置很久的小心愿——这是我理解的、技术应该回赠给生活的部分。

## 七、提交信息（可直接粘贴）

**作品名称**：每日通勤 · Daily Commute

**作品链接**：https://map.fx67ll.com/commute

**作品描述**：
一个面向个人通勤场景的私人地图助手。每天的路线不是简单的"家→公司"两点，而是固定的三段锚点串联：家（江浦）→ 我公司（花神）→ 她公司（江宁）。通用地图只会算家到公司一段，第二段去她那边的路、两段实时用时、分段拥堵、预计到达时间，需要一个专门为自己定制的入口。本作品打开即自动判断上下班方向，把两段路的实时耗时、拥堵彩色条、"我"的位置进度、预计到公司/到她那的时间全部摆好，迟到自动提醒，一键跳导航，天气速览。全程零输入、隐私优先（起点仅显示区域名），用一个人业余时间、AI 辅助编码打磨。它不服务任何 KPI，只服务每天那两段在路上的时间。

**技术栈**：Vue 2 ｜ 高德地图 JSAPI 2.0 ｜ Element UI ｜ 自建请求队列与防抖
